# Contributing to Processing Chess

First of all, thank you for considering contributing to Processing Chess! ♟️

Everyone is welcome to contribute, regardless of experience. Whether you have an idea, found a bug, want to improve existing code, or have implemented a new feature, contributions are always appreciated.

## Language Requirements

**The application is in German, but all project communication must be in English.**

- **Application language:** Keep the program's user interface, messages, and other user-facing text in German.
- **Communication language:** Write all issues, pull requests, comments, questions, explanations, and discussions in English.
- **Code and documentation:** Use English for code identifiers, comments, and technical documentation wherever applicable. Existing German user-facing text should remain German.

**Exception: Multilingual Support**

If you want to contribute a feature that makes Processing Chess support multiple languages, the rule requiring user-facing text to remain German is lifted for that contribution. You are welcome to introduce translations, language selection, localization infrastructure, or other changes needed to support multiple languages.

Please keep all project communication in English, even when working on translations.

## Issues

Have an idea, found a bug, or want to suggest an improvement? Feel free to [open an issue](https://github.com/letsmanuel/processing-chess/issues/new).

You don't need to have a solution ready. Describe the problem, your suggestion, or what you think could be improved. Questions and discussions about the project are welcome, too.

Please write your issue in English.

## Pull Requests

Pull requests are welcome! You don't need permission before working on an improvement. Just make sure that:

- **The code runs locally.** Test your changes on your own machine before submitting a pull request.
- **The program hasn't gotten worse.** Your changes should not break existing features, introduce regressions, or make the overall experience worse. Improvements and new features should preserve existing functionality unless the change explicitly intends to modify it.
- **You're available for questions.** I may ask you to explain parts of your implementation, clarify design decisions, or make changes during review. Please be willing to participate in the discussion and help resolve any questions that come up.
- **Communication is in English.** Describe your changes, explain your decisions, and respond to review feedback in English.

You don't need to write perfect code or know everything about the project. Constructive improvements are what matter, and feedback is part of the process.

## Before Submitting

Please test the program locally and verify that your changes work as intended. Pay particular attention to anything your changes might affect, including existing chess functionality, rendering, sound, and other related features.

When opening a pull request, briefly explain what you changed and why. If your changes fix an existing issue, link that issue where applicable.

Keep all pull request descriptions and related discussions in English. Remember that new or modified user-facing text should remain in German unless your contribution is specifically intended to introduce or improve multilingual support.

## Code Style

Try to follow the existing coding style and structure of the project. Keep changes focused on their purpose and avoid unrelated modifications where possible.

Use English for variable names, method names, class names, code comments, and technical documentation wherever applicable. German text intended for users of the application is the exception, unless you are working on multilingual support.

## Thank You!

Processing Chess is an ongoing project, and contributions from the community can help make it better.

**Don't hesitate to open an issue or submit a pull request.** If your code works locally, doesn't make the program worse, and you're willing to discuss your changes in English, you're welcome to contribute!

Thanks for helping improve Processing Chess! ❤️
